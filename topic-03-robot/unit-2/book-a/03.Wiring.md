# Wiring / pin map

Use this pin map for the workshop RC522 ↔ micro:bit (via EdgeBit) setup.

| RC522 Pin | micro:bit Pin |
| --- | --- |
| SDA / NSS | P16 |
| SCK | P0 |
| MOSI | P15 |
| MISO | P14 |
| RST | Not connected |
| VCC | 3V |
| GND | GND |
| IRQ | Not connected |

## Checklist

- Double-check **SCK is on P0** (not P13 — see Firmware step)
- Confirm VCC is **3V**, not 5V
- Confirm GND is common with the micro:bit
- Leave RST and IRQ disconnected unless a future kit revision says otherwise
