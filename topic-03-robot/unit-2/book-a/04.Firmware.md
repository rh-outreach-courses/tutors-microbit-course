# Firmware notes

## Update RFID firmware / extension

Before the workshop, update the RFID / RC522 MakeCode extension (or related firmware notes in your kit docs) so kits match the working build.

Reference project (facilitators):  
[https://makecode.microbit.org/_ipa2XHEoDX7U](https://makecode.microbit.org/_ipa2XHEoDX7U)

## Known pin gotcha

Older notes or sample projects may use **P13 for SCK**. The working workshop wiring uses **P0 for SCK**.

If RFID reads fail after wiring looks correct:

1. Open the MakeCode project pin configuration for the RC522 / SPI clock
2. Change **P13 → P0** for SCK
3. Re-download to the car micro:bit
4. Retest with a known-good tag held near the antenna
