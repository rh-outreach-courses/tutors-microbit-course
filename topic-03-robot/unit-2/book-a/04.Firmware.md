# Firmware notes

Before the workshop, confirm kits use an RFID / RC522 MakeCode build that matches the **SCK on P9** wiring.

Reference project (facilitators):  
[https://makecode.microbit.org/_YbTgFfazUVa6](https://makecode.microbit.org/_YbTgFfazUVa6)

## Known pin gotcha

Many stock RFID libraries default **SCK to P13**. This workshop uses **SCK on P9**. P0 is the micro:bit’s default audio pin, so a clock signal there makes the speaker tick on every card read. If reads fail after wiring looks correct, the library TypeScript may still be on P13 or P0.

You may also need a `custom.ts` edit for other kit issues (broken EdgeBit pins, weak drive on a pin, mid-session remaps, and so on) — same process, different pin numbers. Do that **with caution** and only after checking the [micro:bit pinout](../book-b/index.html) (many pins are shared with LEDs, buttons, or I2C).
